# Project repair and ownership — 2026-10-26

Codex owns the current reward/instruction/evaluation repair. The user authorized
implementation and explicitly prohibited model execution. That restriction
persists until the user changes it. No training, inference, server start/stop,
model download, or container launch was used in this repair.

## Delivered behavior

- `prompts/work-contract-v1.md` is the default Q4 instruction policy. It replaces
  the contradictory fallback-to-memory instruction with observable outcomes,
  preservation, consequential clarification, error recovery, and honest
  completion. Three demonstrations illustrate these rules. The original mirrored
  Bionic prompt/tool implementation is preserved.
- `ops/reward_contract.py` and `suite-v2/tasks.json` implement four public
  development roots. They grade exact transformation contracts, preserved sources
  and final delivery. They do not use keyword presence as semantic correctness.
- Legacy families/mixes cannot feed the repaired trainer. The legacy real-task
  adapter requires explicit diagnostic intent. Historical evaluation is labelled
  `legacy-diagnostic`, never silently presented as qualified task success.
- A missing verifier executable raises invalidity instead of returning reward
  zero. Empty/all-dropped batches and invalid reward values cannot enter the
  mean/advantage calculation. Family summaries include every sampled family.
- The repaired Q4 trainer/evaluator/raw probe and historical Q4 orchestration
  require explicit model opt-in before model loading. The legacy evaluator also
  requires diagnostic acknowledgement. This is defense in depth; no CLI flag
  overrides the user's no-model instruction.
- `ops/evaluation_integrity.py` verifies raw task files against an explicitly
  supplied external manifest, plus embedded seals, inventory, schema, identities
  and exclusions. Missing/corrupt registries fail closed. A locally writable
  manifest is not described as independent authority.
- Q4 `--holdout` refuses in-process private evaluation before reading tasks or
  loading models. It cannot export private transcripts or per-task feedback.
- Records bind task/contract code, instruction text, tool schemas, and actual
  normal/final system prompts to hashes. The final round removes tool schemas and
  explicitly explains that tools are unavailable. Run directories cannot silently
  overwrite an existing run's configuration.

installation into the active checkout; use that receipt for the installed hashes.
