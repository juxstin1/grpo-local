## Direction decided late tonight (details in NEXT-workspace-gym.md)

- **Target agent design: rebuilt context per call** - every call is a fresh prompt: task -> notes file (capped) ->
  plan -> last few tool results; never earlier thinking. Episodes can run long while each call stays small and
  on-distribution; each call is its own token-exact training segment; note-taking becomes a graded skill.
  (Anthropic calls this family "context engineering": compaction, structured notes, sub-agents.)
- **Sub-agents** (same lane, later): orchestrator keeps task + notes and splits work; workers start clean on one
  sub-task and return a short report. Workers graded on their sub-task, orchestrator on the final result. Same adapter.
- **Three budget tiers of the same design: 8k (default) / 16k / 32k**, notes caps ~1.5k / 3k / 6k. Compare tiers on the
  same gym items (success, calls per episode, tokens per success), pick per task family, train mixed budgets in one
  lineage. Measure real VRAM at 16k/32k on the pod first and raise the pod's `--max-model-len`.
- **Call format (stateful loop): 1 + k calls.** Call 1 = plan + first action; each run call = one tool call + a
  `NOTE: <one line>` the harness appends to the capped notes file; last call = `ANSWER:` + handoff. No calls spent
  only on state. Separate handoff call only when pausing unfinished (graded: can a fresh session finish from it).
  Metrics: success rate + calls-per-success.
- 32k + compaction stays as the fallback lane.
- GRPO on long episodes: start short (<~15 calls), add graded checkpoints for long tasks.
