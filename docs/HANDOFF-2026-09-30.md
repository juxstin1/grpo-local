## How I will stop these from happening again

These are rules I follow from now on; the ones marked (code) are already enforced in the repo.

1. **Ask before outward or destructive actions** — stopping/removing pods, killing runs that aren't
   mine to kill, deleting data. Ambiguous phrasing ("I guess", "probably") → one-line question, never
   a guess. (Saved to memory.)
2. **Anything expected to run > ~90 min is a detached process**, never a harness background job:
   `Start-Process -WindowStyle Hidden` at home, `setsid nohup … &` on the pod, each with a log file and a
   pidfile, and a one-line status command in the handoff. Tunnels included. (Saved to memory.)
3. **Never start/restart a server or change GPU memory while a scored eval or pilot uses that GPU.**
   Either wait, or put the new work on a different card/port that the scored run doesn't share.
4. **Request errors are never outcomes.** (code) `eval.py` logs errored episodes with their family and
   retries them; `handoff-gym/score.py` retries reader requests with backoff and records `None` →
   note marked incomplete and excluded; controls skip errors. Any new scorer must do the same.
5. **One real item end-to-end before any batch** — new model/endpoint, new note mode, new family, new
   waiter script (run it against a path I `ls` first). If the one item looks wrong, the batch doesn't start.
6. **Harness invariants check before building on it** — served prompt ids == local token stream
   (thinking + observations), one budget and one turn cap read from config, graders require an ANSWER,
   cap hits reported. (code) The fidelity checks and `cap_hit`/`stop` labels exist now; I run the
   stream check after any agent/encoding change.
7. **Edits: Edit tool, or a patch script that asserts every match; then `rg` the result.** No multi-line
   `sd`, no escaped-newline Python inside heredocs.
8. **Say "don't train this yet" when the data can't move the number**, with the share it would need.
9. **ETAs only after measuring**: time the first N steps/episodes, quote a range, re-quote if it slips.
10. **Check free VRAM before starting any server** at home or on a pod.
